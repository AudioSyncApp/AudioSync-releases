# AudioSync (beta)

**AudioSync** zet de radio (Bron B, bijv. Grand Prix Radio) gelijk met het tv-geluid (Bron A, bijv. F1TV). Start beide bronnen; na ongeveer een minuut lopen ze synchroon.

## Downloaden
Ga naar **[Releases](https://github.com/skamp85/AudioSync-releases/releases)** en download bij de nieuwste versie:
- **Mac** (Apple Silicon, M1 of nieuwer): het `.dmg`-bestand
- **Windows** (64-bit): het `AudioSync-Setup-….exe`-bestand

De overige bestanden (.zip, .blockmap, .yml) zijn voor de automatische updates; die hoef je niet te downloaden.

> **Tip:** kies bij F1TV als audio **Track FX** (zonder commentaar). Dat maakt het synchroniseren makkelijker voor de app.

## Mac
1. Open het `.dmg`-bestand en sleep AudioSync naar Programma's.
2. Opent hij niet? Rechtermuisknop op de app > **Open**.
3. Start Bron A. De eerste keer vraagt macOS om audio-opname: **toestaan**.
4. Het systeemgeluid wordt daarna **automatisch gedempt**: je hoort het tv-geluid via AudioSync met de schuif bij Bron A (staat op 0). Uitzetten kan onder Synchronisatie > Geavanceerd.
5. Start Bron B: de **radiostream** of een **mp3**.

## Windows
1. Start het `.exe`-bestand en installeer.
2. Waarschuwing "Windows heeft uw pc beschermd"? **Meer info > Toch uitvoeren**.
3. Installeer de gratis [VB-CABLE](https://vb-audio.com/Cable/) en herstart de pc.
4. Stuur het geluid van je browser naar **CABLE Input**: Instellingen > Systeem > Geluid > **Volumemixer** (Windows 10: *App-volume en apparaatvoorkeuren*). Herstart daarna de browser.
5. Kies in AudioSync bij Bron A **CABLE Output** en zet onderaan de output op je **speakers**.
6. Start Bron B: de **radiostream** of een **mp3**.

## Goed om te weten
- Updates gaan automatisch. Je krijgt een melding als er een nieuwe versie klaarstaat.
- Iets vreemds gezien? Klik rechtsboven op **Stuur feedback**.
- Een beta werkt maar een paar weken; daarna vraagt de app om de nieuwste versie.
